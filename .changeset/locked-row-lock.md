### A locked branch shows a lock where a row's "…" menu would be

<!-- migration
area: Editing
action: None
row: Locked branch: tree rows show a lock
-->

**What changed.** On a protected, in-review or approved branch the content tree no longer drops a row's "…" menu without a trace. Each row that would have had a menu shows a lock of the same size, and its tooltip gives the branch's reason ("This branch is in review. Withdraw it to make changes."), on hover, keyboard focus and touch.
