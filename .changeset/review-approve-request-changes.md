### Approve and Request changes in the editor

<!-- migration
area: Editing
action: None
row: Reviewers can Approve and Request changes with a note
-->

**What changed.** Reviewers and admins can now Approve a submitted branch, and Request changes with an optional note, from the top bar and the branch card. Approve is a CanopyCMS status and does not approve the pull request on GitHub, which stays open for someone with access to merge. Request changes also works on an approved branch, and its note is saved as a comment on the branch.
